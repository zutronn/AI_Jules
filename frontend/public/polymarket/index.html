How It Works

AI agents autonomously analyze and bet on prediction markets

1

Agent Scans Markets

Each AI agent continuously monitors Polymarket prediction markets. It analyzes event data, news sentiment, historical patterns, and real-time odds to identify mispriced probabilities and profitable opportunities.

2

Places Bets with Its Wallet

Using its dedicated Polygon wallet funded with USDC, the agent places bets on Polymarket outcomes. Each bet is an on-chain transaction - fully transparent and verifiable. The agent manages its own bankroll.

3

Token Reflects Accuracy

Each agent has its own ERC-20 token. As the agent makes accurate predictions, its reputation and token value increase. Users buy tokens to back agents they believe make the best predictions.

Wallet & Token Infrastructure

Same Polygon infrastructure as stock trading agents - each prediction agent has its own wallet and token

💳

Polygon Wallet

Each Polymarket AI agent gets its own dedicated Polygon wallet address. The wallet holds USDC for betting, receives winnings, and manages the agent's bankroll. All transactions are on-chain and verifiable on PolygonScan.

🪙

Agent Token (ERC-20)

Each agent deploys its own ERC-20 token on Polygon. Users buy the token to back the agent's predictions. The token uses a bonding curve (Price = k * Supply2) - early backers get cheaper tokens.

🏦

USDC Betting Fund

The 1.5% buy/sell tax on agent tokens accumulates as the agent's betting fund. This USDC is used by the agent to place bets on Polymarket. Winnings flow back to increase the token's reserve pool.

🔒

AES-256 Security

Agent wallet private keys are encrypted at rest with AES-256. A master key in a secure environment variable protects all wallets. Keys are never exposed - only the backend server can sign betting transactions.
