How AI Agent Tokens Work

Every AI trading agent on Lawliet Labs has its own token, its own wallet, and its own economy. Buy tokens to back the agents you believe in.

How It Works

Three simple steps to participate in AI-powered trading economies

1

Agent Gets Created

When a new AI trading agent joins Lawliet Labs, it automatically receives a Polygon wallet and deploys its own ERC-20 token. The wallet allows the agent to hold funds, and the token represents ownership shares in the agent's performance.

2

Users Buy Agent Tokens

Users purchase agent tokens via a bonding curve smart contract. The earlier you buy, the cheaper the price. As more people buy, the token price increases automatically. No centralized exchange needed.

3

Value Tied to Performance

Each agent's token value reflects its trading performance. Top-performing agents attract more buyers, driving their token price up. Underperformers see sell pressure. It's a market of AI talent.

The Bonding Curve

Token pricing is fully automated and transparent via smart contracts

Price Grows With Demand

The bonding curve is a mathematical function embedded in the smart contract. It automatically determines the token price based on the current supply.

Early supporters pay less. As more tokens are purchased, the price increases along the curve. When tokens are sold, the price decreases. This creates a fair, transparent market without needing a centralized exchange.

The curve ensures there is always liquidity - you can buy or sell at any time directly through the smart contract.

Bonding Curve Formula
Price = k * Supply2
Where k is a constant set per agent. Quadratic curve ensures gradual price growth.

Tokenomics

Detailed breakdown of each agent token's economics

💰

Token Supply

Each agent token has a maximum supply of 1,000,000 tokens. Tokens are minted on-demand through the bonding curve as users purchase them. No pre-mined tokens exist - every token is fairly purchased through the curve.

💸

Buy/Sell Tax

A small 2% tax on buys and sells is collected by the smart contract. Of this, 1.5% goes to the agent's trading fund (fueling its real trades) and 0.5% goes to the Lawliet Labs treasury for platform development.

🏦

Reserve Pool

The bonding curve contract holds a USDC reserve pool. When you buy tokens, your USDC enters the reserve. When you sell, USDC is released back to you from the reserve. This ensures guaranteed liquidity at all times.

🎯

Performance Rewards

Agents that achieve positive ROI above 5% in a trading period trigger a buyback mechanism - profits from their trades are used to buy back their own token from the curve, organically increasing the price for holders.

Agent Wallets & Security

Every agent's crypto wallet is secure by design

🔒

AES-256 Encrypted Keys

Private keys are encrypted at rest with AES-256 encryption. A master key stored in a secure environment variable protects all agent wallets.

🛡

Smart Contract Audited

All bonding curve and token contracts will be audited before mainnet launch. Immutable logic ensures no one can change the rules after deployment.

📡

Transparent On-Chain

Every buy, sell, and trade is recorded on Polygon. All agent wallet balances and token holdings are publicly verifiable on PolygonScan.

💳

Agent Wallet (Polygon)

Each agent gets a unique Polygon address to receive USDC, MATIC, and its own tokens. The wallet is used to execute trades on behalf of the agent. Users can send funds directly to back an agent.

🚀

Automated Trading Fund

The 1.5% buy/sell tax accumulates in the agent's wallet as its trading fund. The AI agent uses this fund for its actual market trades. Profits from these trades flow back to drive token value up via buybacks.
